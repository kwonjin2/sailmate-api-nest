# 결정 기록

NestJS 구현 중 실제로 선택한 기술 결정과 트레이드오프를 기록하는 파일이다.

이 파일에는 단순 작업 기록이나 진행 상황을 적지 않는다. 나중에 코드를 다시 봤을 때 “왜 이 방식으로 구현했는지”를 설명해야 하는 결정만 남긴다.

## 기록할 결정 예시

- ORM으로 Prisma를 사용할지 TypeORM을 사용할지.
- PostgreSQL 스키마를 어떻게 나눌지.
- access token과 refresh token을 어떻게 발급하고 저장할지.
- refresh token을 DB에 저장할지, rotation을 적용할지.
- 공통 응답 포맷과 에러 응답 포맷을 어떻게 둘지.
- 모임 신청 승인 시 정원 초과를 어떻게 막을지.
- 신청 승인과 멤버 생성을 어떤 트랜잭션으로 묶을지.
- Todo 작성 가능 주차를 어떻게 검증할지.
- 이미지 업로드를 로컬 mock, S3, Supabase Storage 중 무엇으로 처리할지.
- 테스트 DB를 어떻게 구성할지.
- Docker와 환경 변수를 어떤 기준으로 나눌지.
